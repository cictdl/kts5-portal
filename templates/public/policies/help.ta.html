இணையதளத்தில் வழி காணுதல்

  • மேற்பகுதியிலுள்ள பட்டியல் இணையதளத்தின் ஒவ்வொரு பகுதிக்கும் இட்டுச் செல்கிறது. அலைபேசியில், பட்டியல் பொத்தானை அழுத்தி அதைத் திறக்கவும்.
  • பக்கத்தின் மேற்பகுதியிலுள்ள மொழித் தேர்வியைக் கொண்டோ அடிப்பகுதியிலுள்ள மொழிப் பட்டியலிலிருந்தோ உங்கள் மொழியைத் தேர்ந்தெடுக்கவும். இணையதளம் அதை நினைவில் வைத்துக்கொள்ளும்.
  • தள வரைபடம் அனைத்துப் பக்கங்களையும் பட்டியலிடுகிறது.

மாணவர்களுக்கு

மாணவர்கள், பங்கேற்கும் கல்வி நிறுவனங்கள், பொறுப்பு அலுவலர்கள் ஆகியோருக்கான படிப்படியான வழிகாட்டி பங்கேற்கும் முறை பக்கத்தில் உள்ளது.

  1. உங்கள் கல்வி நிறுவனம் பங்கேற்கும் கல்வி நிறுவனமாக இருக்க வேண்டும். {{ settings['camp.from']|date }} முதல் {{ settings['camp.to']|date }} வரை, அந்நிறுவனம் ஆர்வமுள்ள தன் மாணவர்களை மதிப்பீடு செய்யும்: இணையதளத்தின் இணையவழித் தேர்வின் மூலம் (அதன் இணைப்பையும் அணுகல் குறியீட்டையும் உங்கள் நிறுவன ஒருங்கிணைப்பாளர் தருவார்) அல்லது தகுந்த வேறு முறையில். பின்னர் தகுதியின் அடிப்படையில் ஒரு மாணவரைத் தேர்ந்தெடுக்கும்.
  2. தேர்ந்தெடுக்கப்பட்ட மாணவருக்குத் தனிப்பட்ட பதிவு இணைப்பு மின்னஞ்சல் வழியாக அனுப்பப்படும். அவர் {{ settings['reg.end']|date }}-க்குள் பதிவு செய்ய வேண்டும்: ஒளிப்படம், அடையாளச் சான்று, நிறுவனத் தலைவரின் கையொப்பமும் முத்திரையும் கொண்ட பரிந்துரைப் படிவம், நெறியாளர்/வழிகாட்டி ஆசிரியரின் விவரங்கள் ஆகியவை தேவை. விண்ணப்ப எண் மின்னஞ்சல் வழியாக அனுப்பப்படும்.
  3. உங்கள் விண்ணப்ப எண், பிறந்த நாள், அலைபேசி எண்ணின் கடைசி நான்கு இலக்கங்கள் ஆகியவற்றைக் கொண்டு, விண்ணப்ப நிலை பக்கத்தில் உங்கள் விண்ணப்பத்தின் நிலையை அறியலாம். இதே விவரங்களைக் கொண்டு விண்ணப்பதாரர் தளத்தில் நுழையலாம்.
  4. உங்கள் மாநில/ஒன்றியப் பகுதியின் பொறுப்பு அலுவலர் உங்கள் விண்ணப்பத்தைச் சரிபார்ப்பார்; தேர்ந்தெடுக்கப்பட்ட மாணவர்களை CICT மின்னஞ்சல் வழியாகவும் இவ்விணையதளத்திலும் அறிவிக்கும். தேர்ந்தெடுக்கப்பட்ட மாணவர்கள் உதவித்தொகைக்காகத் தங்கள் வங்கி விவரங்களைத் தந்து (காண்க: வழிகாட்டி), தங்கள் ஆய்வுக் கட்டுரையை விண்ணப்பதாரர் தளத்தில் சமர்ப்பிப்பர்.

பங்கேற்கும் கல்வி நிறுவனங்களுக்கு

  1. {{ settings['hei.end']|date }}-க்குள் உங்கள் கல்வி நிறுவனத்தைப் பதிவு செய்க; அல்லது உங்கள் பொறுப்பு நிறுவனத்திடமிருந்து வந்த அழைப்பு மின்னஞ்சல் வழியாகப் பதிவை நிறைவு செய்க.
  2. நிறுவன ஒருங்கிணைப்பாளர் அல்லது நிறுவனத் தலைவரின் மின்னஞ்சல் முகவரியைக் கொண்டு கல்வி நிறுவனப் பக்கத்தில் நுழைக: ஆறு இலக்கக் குறியீடு உங்களுக்கு மின்னஞ்சலில் அனுப்பப்படும்.
  3. {{ settings['camp.to']|date }}-க்குள் உங்கள் மாணவர்களை மதிப்பீடு செய்து, தகுதியின் அடிப்படையில் ஒருவரைத் தேர்ந்தெடுத்து, அம்மாணவர் {{ settings['reg.end']|date }}-க்குள் பதிவு செய்வதை உறுதி செய்க. கல்வி நிறுவனங்களுக்கான வழிகாட்டியை அச்சிடலாம்.

ஆவணங்களும் காணொளிகளும்

  • PDF ஆவணங்கள் உலாவியிலேயே திறக்கும். Adobe Acrobat Reader போன்ற கட்டணமில்லா PDF படிப்பானையும் நீங்கள் பயன்படுத்தலாம்.
  • காணொளிகள் YouTube-இல் திறக்கும்; காணொளியில் துணைத்தலைப்புகள் இருப்பின், CC பொத்தானை அழுத்தி அவற்றை இயக்கலாம்.

திரை வாசிப்பான்கள்

இந்த இணையதளத்தைத் திரை வாசிப்பான்களுடன் பயன்படுத்தலாம்; எடுத்துக்காட்டாக, NVDA (கட்டணமில்லை, Windows-க்கு), JAWS, Windows Narrator, Apple கருவிகளில் VoiceOver, Android அலைபேசிகளில் TalkBack.

உலாவிகள்

Chrome, Edge, Firefox அல்லது Safari உலாவியின் அண்மைப் பதிப்பை, JavaScript இயக்கத்தில் உள்ள நிலையில் பயன்படுத்துக: இணையவழித் தேர்வுக்கும் வகுப்பறை வினாடி வினாவுக்கும் JavaScript தேவை. தேர்வின்போது நிலையான இணைய இணைப்பைப் பயன்படுத்தி, தேர்வைச் சமர்ப்பிக்கும் வரை சாளரத்தைத் திறந்தே வைத்திருக்கவும்.
