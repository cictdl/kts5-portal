இணையதளத்தில் வழி காணுதல்

  • மேற்பகுதியிலுள்ள பட்டியல் இணையதளத்தின் ஒவ்வொரு பகுதிக்கும் இட்டுச் செல்கிறது. அலைபேசியில், பட்டியல் பொத்தானை அழுத்தி அதைத் திறக்கவும்.
  • பக்கத்தின் மேற்பகுதியிலுள்ள மொழித் தேர்வியைக் கொண்டோ அடிப்பகுதியிலுள்ள மொழிப் பட்டியலிலிருந்தோ உங்கள் மொழியைத் தேர்ந்தெடுக்கவும். இணையதளம் அதை நினைவில் வைத்துக்கொள்ளும்.
  • தள வரைபடம் அனைத்துப் பக்கங்களையும் பட்டியலிடுகிறது.

மாணவர்களுக்கு

  1. பரிந்துரைப் படிவத்தைப் பதிவிறக்கி, நிரப்பி, உங்கள் நிறுவனத் தலைவரின் கையொப்பமும் முத்திரையும் பெறுக.
  2. பதிவு செய்ய வேண்டிய காலம்: {{ settings['reg.start']|date }} முதல் {{ settings['reg.end']|date }} வரை. உங்கள் விண்ணப்ப எண் மின்னஞ்சல் வழியாக உங்களுக்கு அனுப்பப்படும்.
  3. உங்கள் விண்ணப்ப எண், பிறந்த நாள், அலைபேசி எண்ணின் கடைசி நான்கு இலக்கங்கள் ஆகியவற்றைக் கொண்டு, விண்ணப்ப நிலை பக்கத்தில் உங்கள் விண்ணப்பத்தின் நிலையை அறியலாம். இதே விவரங்களைக் கொண்டு விண்ணப்பதாரர் தளத்தில் நுழையலாம்; உங்கள் அனுமதிச் சீட்டை அங்கே பெறலாம்.
  4. இணையவழித் தேர்வை {{ settings['exam.date']|date }} அன்று, {{ settings['exam.start_time'] }} முதல் {{ settings['exam.end_time'] }} IST வரை, விண்ணப்பதாரர் தளத்தில் எழுதுக. விவரங்களுக்கு தேர்வு பக்கத்தைக் காண்க.
  5. தேர்வுக்குப் பின் தகுதிப் பட்டியல் வெளியிடப்படும். தேர்வு செய்யப்பட்ட மாணவர்கள் உதவித்தொகைக்காகத் தங்கள் வங்கி விவரங்களைத் தந்து (காண்க: வழிகாட்டி), தங்கள் ஆய்வுக் கட்டுரையை விண்ணப்பதாரர் தளத்தில் சமர்ப்பிப்பர்.

ஆவணங்களும் காணொளிகளும்

  • PDF ஆவணங்கள் உலாவியிலேயே திறக்கும். Adobe Acrobat Reader போன்ற கட்டணமில்லா PDF படிப்பானையும் நீங்கள் பயன்படுத்தலாம்.
  • காணொளிகள் YouTube-இல் திறக்கும்; காணொளியில் துணைத்தலைப்புகள் இருப்பின், CC பொத்தானை அழுத்தி அவற்றை இயக்கலாம்.

திரை வாசிப்பான்கள்

இந்த இணையதளத்தைத் திரை வாசிப்பான்களுடன் பயன்படுத்தலாம்; எடுத்துக்காட்டாக, NVDA (கட்டணமில்லை, Windows-க்கு), JAWS, Windows Narrator, Apple கருவிகளில் VoiceOver, Android அலைபேசிகளில் TalkBack.

உலாவிகள்

Chrome, Edge, Firefox அல்லது Safari உலாவியின் அண்மைப் பதிப்பை, JavaScript இயக்கத்தில் உள்ள நிலையில் பயன்படுத்துக: இணையவழித் தேர்வுக்கும் வகுப்பறை வினாடி வினாவுக்கும் JavaScript தேவை. தேர்வின்போது நிலையான இணைய இணைப்பைப் பயன்படுத்தி, தேர்வைச் சமர்ப்பிக்கும் வரை சாளரத்தைத் திறந்தே வைத்திருக்கவும்.
